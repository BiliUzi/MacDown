# MacDown

面向 Apple 芯片的本地 Markdown 编辑器，最低支持 macOS 12。

[下载安装包](https://github.com/BiliUzi/MacDown/releases/latest) · [构建与发布](BUILD_INSTRUCTIONS.md)

基于 [MacDown](https://github.com/MacDownApp/macdown) 和 [MacDown SE](https://github.com/eldris-io/macdown-se) 修改。许可和第三方署名保留在 `LICENSE/` 及 `MacDown/Localization/Base.lproj/Credits.rtf`。
